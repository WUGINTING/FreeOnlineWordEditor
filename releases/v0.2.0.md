# v0.2.0 — the interface in English and Simplified Chinese

The editor's interface (ribbon, menus, dialogs, panes, notices) now comes in three languages:
Traditional Chinese (`zh-TW`, the default, unchanged), Simplified Chinese (`zh-CN`) and English (`en`).

```bash
npm install papyrus-docx@0.2.0
```

```ts
import { setLocale, createDocxEditor } from 'papyrus-docx';

setLocale(navigator.language);   // 'en-US' → en, 'zh-Hans-CN' → zh-CN, 'zh-HK' → zh-TW, anything else → en
// or: createDocxEditor('#editor', { locale: 'en' })   ·   <DocxEditorVue locale="en" />
```

Without a bundler: <https://cdn.jsdelivr.net/npm/papyrus-docx@0.2.0/dist/papyrus-docx.standalone.iife.js>

## New

- `setLocale`, `getLocale`, `locales`, `matchLocale`: choose the interface language, also from a
  browser's language tag. One language for the whole page; set it before creating the editor.
- The `locale` option of `createDocxEditor` and the `locale` prop of `DocxEditorVue`.
- `addMessages(locale, texts)`: change a text, or add a language of your own. The key is the
  source text in Traditional Chinese; the full list is `src/papyrus/locales/en.ts`.
- `translate(text)`: for a host page that shows one of the editor's exported texts.
- The demo site's language choice now changes the editor as well.
- `npm run i18n`, and a test: every Chinese text in the source is either translated in each
  language file or listed as not being interface text.

## Good to know

- **The English and Simplified Chinese texts are machine-made and not yet reviewed by native
  speakers.** Corrections are welcome: `src/papyrus/locales/`.
- Font names, style names and the document's own text are never translated. New shapes still get
  a Chinese name (「矩形 1」) and the watermark presets are Chinese words: both are written into
  the document.
- What a report says (the compatibility notice, for example) is in the language that was set
  when it was made; it is not made again when the language changes.
- The package's script grew by about 100 kB (48 kB gzipped) for the two language files.

Nothing changes for Traditional Chinese: the source text is the lookup key, so `zh-TW` shows
exactly what it showed in 0.1.0.

**All changes:** <https://github.com/WUGINTING/FreeOnlineWordEditor/compare/5f9c28d...v0.2.0>

## 中文摘要

編輯器介面（工具列、選單、對話框、側邊面板、提示訊息）現在有三種語言：繁體中文（預設，沒有變動）、
簡體中文與英文。用 `setLocale('en')`，或建立時給 `{ locale: 'en' }` 切換；也可以直接給瀏覽器的語言代碼。
英文與簡體中文的翻譯是機器產生的，還沒有經過母語人士校對，歡迎指正。
